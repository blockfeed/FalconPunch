# FalconPunch

FalconPunch is a simple client for sending files to **FBI** on a Nintendo 3DS over the network.

## Overview

Typical use case: transfer a `.cia` from your PC to your 3DS, then install it from inside FBI.

## Requirements

- Nintendo 3DS/2DS with homebrew access
- **FBI** installed
- PC and 3DS on the same network

## Usage

1. On the 3DS, open **FBI**.
2. In FBI, choose the menu option that waits for an incoming network transfer (it usually displays the console's IP address, and sometimes a port).
3. On your PC, run FalconPunch and point it at the file you want to send and the IP/port shown by FBI.
